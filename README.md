# 📰 NewsDarpan AI

> **Structured · Objective · Multi-Perspective · Future-Intelligence**

NewsDarpan is an AI-powered news intelligence platform built for the modern reader who wants facts without spin. Every story is bias-scored, fact-checked, multi-source verified, and readable through neutral, progressive, or conservative lenses — all powered by Claude AI in real time.

## ✨ Features

### 🗞️ Core News Feed
- **Multi-source aggregation** — Every story cross-referenced from 3–5 top sources (Reuters, Hindu, FT, NDTV, etc.)
- **Bias Meter** — 0–100 bias score with Low / Moderate / High label for every article
- **Sentiment Ring** — Visual circular score showing Positive / Mixed / Negative tone
- **Market Ticker** — Relevant index and predicted market move overlaid on each card (e.g. SENSEX +1.2%)
- **Breaking & Trending** — Real-time labels on time-sensitive stories
- **Country filter** — Switch between US / UK / IN / FR / DE / JP / WORLD editions
- **Topic filter chips** — Filter by Adverse Only, High Polarization, Financial, Crime, Geopolitics, AI Ethics, and more
- **Instant search** — Type to filter all stories in real time

### 🤖 AI Features (inside every article)
| Tab | What it does |
|-----|-------------|
| 📰 Summary | Clean, objective summary of the story |
| 🔵 Progressive | Left-leaning analysis generated by Claude |
| 🔴 Conservative | Right-leaning analysis generated by Claude |
| ⚪ Neutral | Strictly factual, no-opinion analysis |
| ⚔️ Live Debate | Liberal vs Conservative AI personas debate the story live, message by message |
| 🧬 News DNA | Radar chart scoring Emotional Tone, Political Lean, Credibility, Urgency, Complexity, Global Relevance |
| 🎯 Impact Calculator | Pick your persona (Student / Farmer / Developer / Investor / Govt) → personalised impact score + action items |
| 🕸️ Story Connections | Causal graph linking this story to 3–4 related events with direction arrows |
| 🗳️ Community Poll | Vote Believable / Suspicious / Important / Irrelevant — live percentage results |
| 💬 Ask AI | Ask anything in English, Hindi, or Hinglish — with suggested prompts |

### 📊 Right Panel Widgets (always visible)
| Widget | What it does |
|--------|-------------|
| 🎓 News Score | Tracks your reading session — grades how balanced your news diet is (A+ to D) |
| 🔮 Future Predictor | Type any topic → AI predicts headlines for 1–3 months, 6–12 months, best/worst case |
| 📈 Topic Trends | Sparkline charts showing 7-day coverage volume for Economy, Tech, Climate, Politics, Science, Geopolitics |
| ☁ Word Cloud | Most-used words across today's headlines, sized by frequency, coloured by sentiment |
| ⏳ Time Machine | See how headlines on any topic looked 1, 5, and 10 years ago + narrative evolution |
| 🔍 Fake News Detector | Paste any headline → verdict (True / Misleading / False / Unverified) + confidence % + red flags |
| 📄 Article Analyzer | Paste any URL or text → credibility score, bias level, fake news risk, adverse classification |
| 🔮 Future Predictor | Per-story: predicted headlines at 7 days, 30 days, 90 days + probability bars |

### 📻 Daily Briefing
- Click **"Briefing"** in the header → Claude writes a full morning news briefing in flowing prose, no bullets

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 (JSX, Hooks) |

## 🔑 API Key Setup

NewsDarpan requires an **Anthropic API key** to power all AI features.

1. Go to [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)
2. Create a new key (starts with `sk-ant-`)
3. When the app loads, paste it into the **yellow banner at the top**
4. Click **"Save & Enable"** — all features unlock instantly

> **Security note:** Your key is stored only in `sessionStorage` (your browser tab). It is never sent anywhere except directly to `api.anthropic.com`. It clears when you close the tab.

## 🧬 How the AI Features Work

### News DNA Scores
The radar chart scores each story across 6 dimensions (0–100):
- **Emotional Tone** — How emotionally charged the language is
- **Political Lean** — How far left or right the framing skews
- **Credibility** — Source reliability and claim verifiability
- **Urgency** — How time-sensitive or breaking the story is
- **Complexity** — How technically or intellectually dense the content is
- **Global Relevance** — How much the story matters beyond one country

These are AI-generated scores, not API key values — Claude reads each article and returns its assessment in JSON format.

### Multi-Perspective Analysis
Claude is prompted with explicit persona instructions:
- **Progressive lens** — Frames through equity, environment, social policy
- **Conservative lens** — Frames through economy, security, individual liberty
- **Neutral lens** — Pure facts and verified data only

### Future Predictions
The predictor asks Claude to simulate plausible future headlines at 7, 30, and 90 days, with probability distributions across positive, neutral, and negative outcomes.
